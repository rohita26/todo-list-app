To-Do List Application

A production-quality, object-oriented task manager with 16 features, clean architecture, and in-memory storage using ArrayList.

Why can't I use the app here?
This is a Java console application — it runs in your terminal with the JVM, not in a web browser. Netlify hosts static websites; it cannot execute Java programs. Use the links below to view the source code and run it locally on your machine.
View on GitHub How to Run Locally

Features

  • Add, view, update & delete tasks
  • Search by ID or title
  • Mark tasks as completed
  • View pending & completed tasks
  • Filter by priority (LOW / MEDIUM / HIGH)
  • Sort by due date or priority
  • Task statistics & counts
  • Formatted table output
  • Input validation & error handling
  • 10 pre-loaded sample tasks

# Prerequisites: JDK 17+ installed

git clone https://github.com/rohita26/todo-list-app.git
cd todo-list-app/src

javac -encoding UTF-8 model/*.java exception/*.java service/*.java util/*.java Main.java
java Main

Tech Stack

Model · Service · Util layers with SOLID principles and custom exceptions.
